- 来源:[bwks/network-icons-svg](https://github.com/bwks/network-icons-svg)
- 许可:GPL-3.0(见 `LICENSE`),与 scanopy 的 AGPL-3.0 兼容。

| 文件 | 上游 | 用途(角色) |
|---|---|---|
| router.svg | generic-router-colour | 核心 core |
| switch-l3.svg | generic-switch-l3-colour | 汇聚 agg(L3) |
| switch-l2.svg | generic-switch-l2-v2-colour | 接入 acc(L2) |
| firewall.svg | generic-firewall-v2-colour | 安全 sec |
